# RDS module

Amazon RDS PostgreSQL in isolated data subnets, Multi-AZ, encrypted with a
customer-managed KMS key, with master credentials stored in AWS Secrets Manager.

## Zero Trust properties

- `publicly_accessible` is forced `false` via validation.
- The DB security group allows port 5432 **only** from the application security group
  (SG reference); egress from the data tier is denied.
- Storage and Performance Insights are encrypted with the customer-managed `rds` KMS key.
- The master password is generated by Terraform and stored in Secrets Manager encrypted
  with the `secrets` KMS key. The secret **value** is never output.
- Deletion protection and automated backups are enabled by default.

## Notes

- The secret version `lifecycle.ignore_changes` keeps the secret in sync after the RDS
  endpoint is created while preventing Terraform from overwriting manual rotations.
- Use AWS Secrets Manager rotation for production; this module provisions the secret but
  does not create a rotation Lambda (kept out of scope for a reference architecture).
